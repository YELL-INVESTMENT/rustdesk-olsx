Au premier lancement

Les deux systèmes affichent un avertissement, parce que le logiciel n’est pas distribué par un grand éditeur. Voici comment passer outre.

Windows

Ouvrez le fichier téléchargé et suivez l’installation.

Un écran bleu apparaît, intitulé Windows a protégé votre ordinateur. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

macOS

Ouvrez l’image téléchargée, puis glissez l’application dans le dossier Applications.

Au premier lancement, macOS affiche Apple n’a pas pu vérifier que cette app ne contient pas de logiciel malveillant. C’est normal, l’application n’est pas distribuée par l’App Store. Ne cliquez pas sur Déplacer vers la corbeille, cliquez sur Terminé.

Ouvrez ensuite Réglages Système, rubrique Confidentialité et sécurité. En bas de la section Sécurité, une ligne mentionne l’application avec un bouton Ouvrir quand même. Cliquez dessus et confirmez. C’est à faire une seule fois.

Sur les versions de macOS antérieures à Sequoia, le raccourci existe encore : clic droit sur l’application, puis Ouvrir.

Autorisez enfin l’application dans cette même rubrique Confidentialité et sécurité :

  • Enregistrement de l’écran, pour que nous voyions votre écran
  • Accessibilité, pour que nous puissions utiliser le clavier et la souris

Ce que fait ce logiciel, et ce qu’il ne fait pas

Il ne tourne que lorsque vous l’ouvrez. Il ne démarre pas avec l’ordinateur et n’attend pas en arrière-plan.

Vos sessions passent uniquement par le serveur d’OLSx. L’adresse et la clé de ce serveur sont inscrites dans le fichier que vous installez, aucun autre serveur n’est joignable.

Le code source complet est publié. N’importe qui peut vérifier ce que fait le logiciel, ligne par ligne.
