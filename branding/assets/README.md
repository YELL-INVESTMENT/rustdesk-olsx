# Sources graphiques

Déposer ici le logo OLSx, puis lancer `../gen-icons.sh` à la racine du dépôt.

| Fichier | Attendu | Rôle |
|---|---|---|
| `logo-square.png` | carré, 1024 × 1024, fond transparent | icône de l'application, toutes plateformes |
| `logo-wide.png` | optionnel, bandeau horizontal | logo affiché dans l'interface |

Les icônes générées à partir de ces fichiers sont versionnées dans `res/` et
`flutter/`. La compilation n'a donc besoin d'aucun outil graphique.
